技能名称

剪映自动化视频制作技能

技能简介

面向剪映专业版（Jianying Pro）的智能视频制作技能，通过 AI 与自动化流程协同工作，实现从素材整理、分镜规划、字幕生成到视频导出的全流程自动化处理，大幅降低短视频制作成本，提高内容生产效率。

该技能支持直接生成可编辑的剪映工程，也支持通过 FFmpeg、桌面自动化等方式完成视频初剪，适用于知识分享、历史解说、城市文化、旅游攻略、书籍推荐等各类短视频内容创作。
